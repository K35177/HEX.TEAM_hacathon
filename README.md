# HEX Acoustic Modem — Windows Release

Готовая клиентская версия 0.7.2 для передачи файлов через динамик и микрофон.

## Скачать и запустить

Скачайте [`AcousticFileTransfer.exe`](AcousticFileTransfer.exe) и запустите его
двойным щелчком. Это автономное приложение для Windows x64: Python, C++ runtime,
установщик и дополнительные файлы не требуются.

Для передачи используйте одинаковую версию приложения на обоих компьютерах:

1. на принимающем компьютере нажмите «Принять файл»;
2. на передающем компьютере выберите «Передать файл»;
3. выберите профиль «Турбо» и передаваемый файл.

Windows SmartScreen может предупредить о неизвестном издателе, поскольку файл
пока не подписан коммерческим сертификатом.
