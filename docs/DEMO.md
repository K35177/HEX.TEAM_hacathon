# Инструкция по демонстрации

## Подготовка

1. Собрать проект командой `make` на двух ноутбуках.
2. Выполнить `make test` и показать успешную самопроверку.
3. Положить небольшую PNG-картинку или бинарный файл до 10 КБ в
   `artifacts/samples/`.
4. Расположить ноутбуки на расстоянии 0,5–1 м.

## Основной сценарий MVP

1. Показать исходный файл, его размер и контрольную сумму.
2. На принимающем ноутбуке запустить `receive`.
3. На передающем ноутбуке запустить `send`.
4. Во время звучания показать прогресс воспроизведения и записи, затем
   обнаружение chirp-преамбулы.
5. После завершения открыть восстановленный файл.
6. Показать совпадение итоговой SHA-256 и статус `integrity: OK`.

## Резервный сценарий

Если в помещении слишком шумно, показать детерминированный программный цикл:

```bash
./build/acoustic-transfer encode artifacts/samples/demo.txt artifacts/recordings/demo.wav
./build/acoustic-transfer decode artifacts/recordings/demo.wav artifacts/received/demo.txt
cmp artifacts/samples/demo.txt artifacts/received/demo.txt
```

Этот резервный режим проверяет тот же пакетный протокол, 4-FSK, chirp, CRC32 и
SHA-256, но не доказывает устойчивость физического акустического тракта. Для
основной демонстрации необходим успешный тест на двух устройствах.
